================================================================================
                            HOW IT WORKS
================================================================================

USER FLOW:
1. User navigates to supplier dashboard
2. Sees language buttons in sidebar (EN, हिं, বাঙ্গ, தமிழ், मराठी)
3. Clicks desired language button
4. Active button highlights with gradient
5. Page reloads with 300ms delay (visual feedback)
6. Language preference saved to localStorage
7. Next visit automatically uses saved language

DEVELOPER FLOW:
1. Access languageManager in JavaScript
2. Use languageManager.translate('key.name') for translations
3. System returns text in currently selected language
4. Page reload mechanism ensures all content translated
